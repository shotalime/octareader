# Release checklist OctaReader MVP

Дата подготовки: 2026-08-30.

Релиз разрешён только после прохождения автоматических проверок и ручного
smoke-теста на реальном iPhone/Safari. Playwright WebKit подтверждает
кросс-браузерную совместимость desktop-движка, но не заменяет проверку iOS,
установленной PWA и реальной квоты хранилища.

## Автоматические проверки

- [x] `npm run validate`: typecheck, lint, 113 unit/integration-тестов и build.
- [x] `npm run test:e2e`: 24 E2E прошли в Chromium/WebKit, 2 WebKit-сценария
  ожидаемо пропущены из-за ограничений Blob/crypto на HTTP preview-origin.
- [x] Offline app shell после остановки origin-сервера — Chromium и WebKit.
- [x] Локальный MVP-сценарий (прогресс, словарь, повторение, ключ, кеш, полная
  очистка) — Chromium и WebKit.
- [x] Импорт и сохранение EPUB после reload — Chromium; WebKit HTTP preview
  ограничение документировано и переносится в реальную iOS-проверку.
- [x] Тап внутри EPUB, слово и предложение — Chromium; реальный iOS gate ниже.

## Обязательный iPhone/Safari smoke-test

Условия: актуальная iOS, Safari без подключённого desktop debugger, deployment
по HTTPS. Записать модель устройства, версию iOS, URL/commit и результат каждого
пункта.

- [ ] Открыть сайт online, установить через «На экран Домой», запустить PWA.
- [ ] Импортировать валидный EPUB из Files; закрыть и повторно открыть PWA.
- [ ] Повторно импортировать тот же файл и убедиться, что предлагается открыть
  существующую книгу.
- [ ] Открыть книгу, перелистнуть страницу и главу, перейти через TOC.
- [ ] Изменить шрифт, интервал, поля и тему; CFI и логический процент не должны
  сброситься.
- [ ] Тапнуть слова с внешней пунктуацией, внутренним апострофом и дефисом;
  предложение не должно пересекать абзац, заголовок или `li`.
- [ ] Свернуть PWA сразу после перелистывания, вернуть её и проверить позицию.
- [ ] Online получить перевод тестовым ключом, сохранить слово и контекст.
- [ ] Включить авиарежим, перезапустить PWA, открыть книгу и кешированный перевод,
  сохранить слово, открыть словарь и оценить карточку.
- [ ] Offline запросить новый перевод и увидеть контролируемую ошибку без потери
  ранее сохранённого кеша.
- [ ] Offline удалить книгу: словарная запись и текст контекста должны сохраниться,
  переход к книге должен стать недоступен.
- [ ] Удалить API key: кешированный перевод должен сохраниться.
- [ ] Установить обновлённую сборку поверх старой, принять уведомление обновления
  и проверить сохранность книг, позиции, словаря и кеша.
- [ ] Подтвердить «Удалить все данные», перезапустить PWA и увидеть пустую
  библиотеку, словарь и очередь повторения.
- [ ] Если доступно мало места, проверить контролируемую ошибку квоты и отсутствие
  частичной книги. Если воспроизвести нельзя, явно записать это как непроверенное.
