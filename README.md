# OctaReader

Offline-first PWA для чтения reflowable EPUB 2/3 и изучения иностранных слов.
Интерфейс приложения — на русском языке; книги, прогресс, ключ Gemini, кеш
переводов и словарь хранятся локально в IndexedDB.

## Запуск

Требуется Node.js `24.11.1` (версия также зафиксирована в `.nvmrc`).

```sh
npm install
npm run dev
```

Production-сборка и локальный preview:

```sh
npm run build
npm run preview
```

Для установки PWA откройте production-версию по HTTPS (localhost допустим для
разработки), дождитесь регистрации Service Worker и используйте команду
установки приложения в браузере. После первой успешной загрузки app shell
доступен без сети.

## Проверки

```sh
npm run validate
npm run test:e2e
```

`validate` запускает строгую проверку TypeScript, ESLint, unit/integration-тесты
и production build. E2E-набор запускается в Chromium и Playwright WebKit.

Перед выпуском обязательно выполните [release checklist](docs/release-checklist.md),
включая ручную проверку установленной PWA на реальном iPhone/Safari. Desktop
WebKit не воспроизводит все ограничения iOS.

## Ограничения MVP

- Поддерживаются только обычные reflowable EPUB 2/3 без DRM; fixed-layout,
  повреждённые и защищённые книги отклоняются контролируемой ошибкой.
- Для нового перевода и проверки API key нужен интернет. Чтение, кешированные
  переводы, словарь и повторение работают локально.
- Доступный объём IndexedDB определяется браузером и устройством, особенно на
  iOS. Приложение не задаёт собственного лимита размера EPUB.
- API key хранится в IndexedDB и не защищён от JavaScript-кода страницы, XSS и
  расширений браузера; этот риск принят для MVP.
- Экспорт, синхронизация, аккаунты, DRM, fixed-layout, закладки, заметки и
  ручное сохранение произвольных фрагментов не входят в MVP.
